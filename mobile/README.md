# Brain on Android, iPhone, iPad, Windows and Mac

**Every device: install the web app.** Open your Brain's https address, then:
- **Android (Chrome):** menu → Install app.
- **iPhone/iPad (Safari):** Share → Add to Home Screen.
- **Windows/Mac (Chrome or Edge):** install icon in the address bar.

It gets its own icon, push notifications, and can share location and camera photos with your Brain when you allow it.

**Android app (.apk), free:**
1. In GitHub, open Actions → **Build Android app** → **Run workflow**, and enter your Brain's https address.
2. After about 5 minutes, download **Brain-android** from the run. Unzip it to get `Brain.apk`.
3. Open it on the phone and allow "install unknown apps" once.

Publishing to the Play Store is optional and needs a one-time $25 Google developer account.

**iPhone app in the App Store:** Apple requires a Mac and a paid developer account ($99/year), so the free route is the installed web app above. It supports notifications on iOS 16.4 and later.

**Computer control:** install the Brain Companion (Control tab) on Windows, Mac or Linux.
