# Security

Please don't open a public issue for a security problem. Use GitHub's "Report a vulnerability" button
(Security tab) on this repository, with steps to reproduce. You'll get an answer within a week.

Especially welcome: ways around DM pairing or webhook signatures, getting the Brain to follow instructions from
web pages, emails or files (prompt injection), leaking vault secrets to the model, reaching private network
addresses from the server, or one user reading another user's Brain on a shared server.
