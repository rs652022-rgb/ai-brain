Telegram

  1. In Telegram, open @BotFather, send /newbot, pick a name, and copy the token.

Discord

  1. At discord.com/developers → New Application → Bot: copy the token and switch on Message Content Intent.
  2. Invite the bot to a server (OAuth2 → URL generator → bot), or just DM it. In servers it answers when mentioned.

Slack

  1. At api.slack.com/apps → Create app → turn on Socket Mode (make an app token with connections:write).
  2. Add bot scopes chat:write, im:history, app_mentions:read, subscribe to message.im and app_mention events, install it, and copy the bot token.

Workflows

Steps that run in order, with stops for your approval. One step per line: prompt: … (use {{previous}} for the last step's result), approve: question, send: telegram (or web, discord, slack, email, whatsapp…), tool: web_search {"query": "…"}. To run one on a schedule, schedule a job whose task is workflow:<id>.

Standing orders

Email watcher

Reads new mail in a mailbox you choose (it doesn't mark anything as read) and tells you only what needs attention. Emails are treated as untrusted: while reading them the Brain can't send messages, browse or use your devices. Gmail needs an app password.

  2. Settings → Developer options → switch on USB debugging (and on Xiaomi/Redmi/POCO also USB debugging (Security settings)).

What it may do

Allowed: does it without asking. Ask me: stops and waits for your OK on each step. Off: never. Calls, messages, shutting down and deleting always ask, whatever you choose.

Folders it can use

It can only read and change files inside these folders (one per line). Deleting never erases anything: files are moved to a _deleted_by_brain folder so you can undo.

Always in your hands

  • Press Stop everything, say or type stop, or push the mouse hard into any screen corner: it stops at once.
  • It never types passwords, OTPs, PINs, card or bank details, never pays, and never solves CAPTCHAs. It hands those to you.
  • Instructions written on websites, emails or messages on screen are ignored; it only follows you.
  • Dangerous commands (wiping disks, disabling antivirus, downloading and running code) are blocked outright.
  • Every step is in the Activity log, which can't be edited.
